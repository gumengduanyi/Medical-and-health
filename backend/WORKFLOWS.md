# 资料工作流

本轮提供确定性核查流程，由后端规则执行；不要求额外的多智能体框架或模型。

## 接口

以下接口均要求登录，并只处理本次请求明确提交的资料，不会自行查询全库个人资料。

| 接口 | 请求 | 返回 |
| --- | --- | --- |
| POST /api/workflows/verify | fields 数组 | 缺失、重复、无效日期、低置信度核对项 |
| POST /api/workflows/cabinet | medicines 数组；可选 as_of、low_stock、expiry_days | 库存、临期、过期、身份缺失及可能重复记录 |
| POST /api/workflows/trends | records 数组 | 按同名指标和相同单位分组的已确认结果、变化量、参考范围变化和排除原因 |
| GET /api/workflows/sources | 无 | 百科、监管查询和企业说明书来源的实际接入状态 |

默认低库存阈值为 3，临期阈值为 30 天；前端药箱显示这些默认值，接口允许指定阈值。当前库存沿用现有字段，不推断天数。重复检查依赖批准文号、规格和厂家，不能替代成分重复检查；现有药品模型没有结构化成分，因此尚不输出重复成分结论。

报告只处理 `status=已确认`、有效检查日期、明确有限数值且带单位的结果。不同单位分别展示，不自动换算；同一指标同日多条结果不计算变化量，参考范围变化单独提示。结果保留报告 ID 和日期作为证据。检查方法不同的同名指标仍需人工核对，不能据此诊断。

## OCR 归档

前端支持编辑识别值、单位和检查日期。归档前调用资料核对接口，显示核对清单和确认弹窗；`POST /api/ocr/confirm` 必须带 `confirmed=true`，报告还需要 `recordDate=YYYY-MM-DD`。缺少日期不会用上传日期冒充检查日期。药品有效期不再用生产日期填充。

报告录入支持多张图片和报告附件，通过 `POST /api/reports` 保存。该接口要求 `confirmed=true` 和有效的 `reportTime`，归档为“已确认”记录以参与趋势分析；前端提交用户编辑后的字段，并在提交前执行资料核对。多张图片作为附件保存，目前只自动识别首张图片，不代表已完成所有附件的 OCR。

识别产生的图片和 OCR 输出仍沿用现有临时存储；确认控制正式业务入库。本轮未建设完整的 OCR 确认审计、临时文件到期清理或业务记录去重机制。

## 说明书拆分和确认

- `leaflet_browser.py`：独占工作线程持有 Playwright，跨请求只在该线程创建、读取和释放浏览器；每次访问创建新页面。
- `leaflet_parser.py`：章节边界、别名归一化和目标章节提取。
- `leaflet_identity.py`：匹配、未提供、明确冲突分开表示。
- `leaflet_candidates.py`：按用户保存短期内存快照，默认 30 分钟到期、最多 100 份；重启/多进程会丢失候选，需要重新发现。
- `leaflet_service.py`：工作流编排、用户确认后归档、管理员审核和向量同步状态。

先调用 `/api/leaflets/auto-discover`，再用返回的 `candidate_id`、`content_hash`、相同药品身份字段以及 `confirmed=true` 调用 `/api/leaflets/import-baike`。不再重新抓取页面；内容、用户或药品身份不一致时拒绝导入。旧客户端必须升级，不能绕过确认直传药名导入。

确认人和确认时间存入说明书表，归档状态为 `pending_review`；管理员审核后为 `approved`，RAG 只读取已审核内容。索引状态为 `pending/synced/failed/disabled`；失败时管理员可再次审核同一记录重试。数据库初始化为既有表添加确认和索引状态字段。历史未记录确认人的待审资料必须重新发现和确认。

百科置信度上限为 0.49，来源权威等级单独保留。只允许读取公开页面，遇到登录、验证码或访问限制停止。

## 正式来源调查与限制

- 国家药监局：https://www.nmpa.gov.cn/datasearch/home-index.html ，本次直接请求返回 412，列为待核实的批准身份查询入口，不宣称能够下载完整说明书。
- 诺华电子说明书：https://www.e-leaflet-novartis.com.cn/#/pc ，已验证浏览器页面列出产品和具体规格 PDF 链接。页面注明仅向专业人士提供，因此目前仅登记来源链接，自动读取适配器仍需确认适用范围和授权。未下载或解析 PDF。
- 百科继续作为辅助候选，不能替代企业/监管机构正式资料。
